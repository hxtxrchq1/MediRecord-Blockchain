# MediRecord Blockchain

Contratos inteligentes del prototipo universitario MediRecord. Este repositorio representa la capa blockchain del proyecto: registra permisos y trazabilidad mediante contratos desplegables en Ethereum Sepolia.

Los documentos médicos y los datos personales permanecen fuera de la blockchain. La red almacena únicamente identificadores, estados de autorización y evidencias criptográficas mínimas, evitando publicar información clínica sensible.

## Alcance

- Registry de recursos y participantes.
- Credenciales de acceso representadas mediante tokens no transferibles.
- Integración prevista con el frontend mediante ethers.js.
- Red de demostración: Ethereum Sepolia.

> Proyecto educativo/prototipo. No utilizar con datos médicos reales ni en producción sin una auditoría de seguridad y privacidad.
